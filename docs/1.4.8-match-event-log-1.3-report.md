**Total Soccer: Mundial — MATCH.EVENT.LOG.1.3, 4 жовтня 2026**

Виправлено порядок шарів Event Log і блокування його input під Pause/Rules. Continue і Back зберігають стан журналу; Restart створює нову сесію. Версія залишається 1.4.8, Android versionCode 8. Цільові тести, браузерні сценарії, build та diff check пройшли. Повний набір має 4 kit-помилки; за явним рішенням користувача metadata залишено як є, а помилки наведено нижче.

Причина layering bug: Event Log був окремим scene-root Container із depth 2500, тоді як Pause і Rules мають root depth 1000. Їхній dim overlay — перший дочірній елемент modal root, тому порядок між roots визначає depth контейнера, а не локальний depth dim rectangle. Журнал із depth 2500 перекривав і затемнення, і modal UI.

Отже, gameplay → Event Log → dim → modal panel. Існуючі modal depths і children order збережено. Журнал не приховується через `setVisible(false)` при відкритті модалки: він залишається logically open і затемнюється разом із полем.

Зміни цього patch відносно початкового незакоміченого пакета:

- `src/ui/EventLogView.ts`: depth 950, `setInputEnabled`, захист drag/wheel/toggle і очищення активного drag при зміні input lock.
- `src/scenes/GameScene.ts`: score callback проходить через перевірку modal state; input синхронізується при відкритті/закритті модалок, Restart/Exit, завершенні матчу та shutdown.
- `src/tests/matchEventUi.test.ts`: 10 нових regression cases для depths, input, open/closed state, Continue, Rules, мови Rules, Restart confirmation, navigation і shutdown.
- Цей звіт та докази у `reports/event-log-1.3/`.

`GameScene.syncEventLogInput()` дозволяє взаємодію лише за enabled scene input, відсутності Pause/Rules/About/confirmation/finished modal та відсутності shutdown/navigation. `EventLogView.setInputEnabled(false)` вимикає Phaser Zone і скидає drag; handlers додатково перевіряють lock, а `toggle()` ігнорує виклик під модалкою. Після Continue/Back повертається лише можливість input: `toggle()`, `refresh()` і `setScroll()` для відновлення не викликаються. Закритий журнал залишається закритим; відкритий зберігає scroll, history, row bindings і mask. Старий drag не продовжується після закриття модалки.

При Restart Phaser може знищити display objects раніше, ніж викличе GameScene shutdown listener. Input lock перевіряє наявність `scene` перед зверненням до Zone; окремий regression test покриває цей порядок. Реальний Restart у Chrome також завершився без runtime exceptions.

Геометрія, compact formatter, 24 px rowHeight, 25 pooled Text rows, одна shared geometry mask і virtualization не змінені. Lock не перебудовує rows і не додає per-frame роботи. Regression checks підтверджують відсутність нових textures/objects на modal transitions, збереження row bindings, no-op refresh і ring reuse при scroll.
