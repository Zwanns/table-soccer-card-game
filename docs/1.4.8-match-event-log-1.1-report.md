# MATCH.EVENT.LOG.1.1 + SCOREBOARD.EVENTS.1.1

Виконано 2026-10-04. Версія залишається **1.4.8**, Android **versionCode 8 / versionName 1.4.8**.

Причина збою після приблизно 50 ходів: попередній formatter створював багаторядкові блоки з командами, номерами та іменами; wordWrap додавав переноси довгих імен; між подіями додавалися порожні рядки. Уся історія рендерилася одним Phaser Text, а maxScroll залежав від його динамічної height. Через resolution 2 ріст логічної висоти одночасно створював удвічі вищу canvas-текстуру, яка могла перевищувати GPU MAX_TEXTURE_SIZE. Це пояснює і нерівномірний ріст, і зникнення нових записів у довгому матчі. Точний момент залежить від кількості подій, довжини імен та GPU пристрою.

Headless-відтворення попереднього алгоритму з 100 verbose BEAT-подіями: logical height **9173 px**, canvas height **18346 px**, GPU MAX_TEXTURE_SIZE **16384 px** — ліміт перевищено. Це відтворення в Edge/WebGL, а не вимірювання на фізичному Android-пристрої.

- `src/ui/EventLogView.ts` — фіксовані рядки, обмежений пул рендерингу та deterministic scroll.
- `src/tests/matchEventLog.test.ts` — exact formatting, canonical ranks, move numbering, notifications, durations, priority.
- `src/tests/matchEventUi.test.ts` — довга історія, геометрія, clipping, touch-scroll та marquee.

Compact formatter: **`formatMatchLogEntry()` у `src/ui/matchEventPresentation.ts`**. Visible prefix використовує **event.moveNumber**, захоплений з **state.matchStepCount**; internal sequence і turnNumber залишаються в моделі. Команди, player identity, shirt numbers, GK identity та score snapshots залишаються в structured data. Visible log не показує команд, імен, номерів футболістів або context. Internal FAILED відображається як FAIL. Rank symbols отримуються через існуючий `getCardRankDisplayLabel()` без нового mapping; J відображається як V, Joker також використовує поточне canonical card UI label.


Усі formatter outputs single-line; CR/LF видаляються defensive check. Якщо defending card відсутня, вона не вигадується.

- **wordWrap OFF**: `{ width: 0, useAdvancedWrap: false }`.
- Кожний Text має fixedWidth **256 px** і fixedHeight **24 px**; overflow обрізається, висота не змінюється.
- Panel незмінна: **x 660, y 140, width 280, height 520**.
- Static header y 10; viewport починається на local y **40**, має height **468 px** і geometry mask нижче header.
- **contentHeight = entries.length × 24**.
- **maxScroll = max(0, contentHeight − 468)**.
- **rowY = 40 + index × 24 − scrollY**; Text.height/getBounds не впливають на layout або scroll.

- Touch drag і wheel збережені; відкриття показує newest; append біля bottom (≤32 px) переходить до newest; читання старих подій зберігає scroll position.
