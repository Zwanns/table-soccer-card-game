Mobile landscape tooltip прилягає до верхнього краю карти; Match Rules отримали більший текст і ширший viewport. Desktop геометрія та типографіка збережені. Версія залишається 1.4.8 / Android code 8.

Причина зазору tooltip — спільний vertical gap 24 px. Тепер mobile gap = 0, desktop gap = 24. Якір використовує реальні world-space кути карти з урахуванням scale, rotation і parent transform. Округлення вниз залишає не більш ніж субпіксельний зазор та не накриває карту. Panel background не має додаткового shadow/offset.

На mobile tooltip використовує фактичний camera viewport: це дозволяє розмістити його над верхнім рядом, де попередній header-safe viewport переводив його під карту. Захисна межа — 12 scene px від viewport. Якщо зверху фізично бракує місця, збережено fallback під карту, тепер також без зазору. Центрування, horizontal clamp, font 28 px, single-line ellipsis, розмір panel, hover/hold/release та card click callbacks збережені. Desktop продовжує використовувати переданий header-safe viewport і попередній fallback.

Причина дрібного Match Rules text — overlay використовував desktop font sizes незалежно від mobile detector. Додано `getMatchRulesLayout`, який обирається через наявний `isMobileLandscapeLayout`. GameScene та TournamentPenaltyScene вже використовують спільний overlay, тому scene routes змінювати не знадобилося.
