# Как менять цвет номеров на экипировках команд

Эта инструкция нужна, если номер игрока на форме плохо читается или хочется поменять его цвет для отдельной сборной.

## Где находятся настройки

Цвета номеров задаются в файле:

```text
src/data/teamKits.ts
```

Ищите в этом файле список `TEAM_KIT_STYLE_ROWS`. В нем у каждой команды есть строка с кодом команды и цветами экипировки.

Номер рисуется игрой поверх формы, поэтому достаточно поменять цвета в `src/data/teamKits.ts`.

## Какие параметры отвечают за цвет

В коде используются два параметра:

```ts
shirtNumberColor
shirtNumberStrokeColor
```

`shirtNumberColor` — основной цвет номера.

`shirtNumberStrokeColor` — цвет обводки номера.

В списке `TEAM_KIT_STYLE_ROWS` строка команды выглядит так:

```ts
['flagCode', 'основной цвет формы', 'второй цвет формы', 'акцент', 'shirtNumberStrokeColor', 'shirtNumberColor']
```

Последний цвет, `shirtNumberColor`, может быть не указан. Тогда игра берет второй цвет формы как цвет номера.

## Как найти нужную команду

1. Откройте `src/data/teamKits.ts`.
2. Найдите `TEAM_KIT_STYLE_ROWS`.
3. Найдите строку нужной команды по `flagCode`.

Например, у Nigeria реальный `flagCode` в проекте:

```text
ng
```

Строка Nigeria сейчас выглядит так:

```ts
['ng', '#008753', '#FFFFFF', '#FFFFFF', '#FFFFFF', '#000000']
```

Здесь:

- `#FFFFFF` перед последним цветом — белая обводка номера;
- `#000000` в конце — черный номер.

## Пример изменения цвета номера

Если нужно сделать для Nigeria черный номер с белой обводкой, строка должна быть такой:

```ts
['ng', '#008753', '#FFFFFF', '#FFFFFF', '#FFFFFF', '#000000']
```

`#000000` — черный номер.

`#FFFFFF` — белая обводка.

Если нужно сделать белый номер с почти черной обводкой:

```ts
['ng', '#008753', '#FFFFFF', '#FFFFFF', '#111111', '#FFFFFF']
```

## Популярные цвета

```text
#000000 — черный
#FFFFFF — белый
#111111 — почти черный
#F5F5F5 — почти белый
#FFD700 — золотой
#FF0000 — красный
#0033A0 — синий
#00843D — зеленый
```

Важно писать цвет в формате `#RRGGBB`: решетка и 6 символов. Буквы лучше писать большими.

## Как проверить результат в игре

1. Сохраните файл `src/data/teamKits.ts`.
2. Запустите проект:

```bash
npm run dev
```

3. Откройте экран `Teams`.
4. Выберите нужную сборную.
5. Посмотрите preview-карту справа.
6. Затем запустите матч этой командой и проверьте игровые карты.

## Проверки перед коммитом

Перед коммитом запустите:

```bash
npm test
npm run build
```

Если менялись только цвета номеров, `validate:kits` обычно не нужен, потому что WebP-ассеты не менялись.

## Как закоммитить изменение

Пример команд:

```bash
git status
git add src/data/teamKits.ts docs/team-shirt-number-colors.md
git commit -m "Document shirt number color settings"
git push
```

Если `ToDo.md` изменен только как рабочий task-файл, не добавляйте его в commit.
