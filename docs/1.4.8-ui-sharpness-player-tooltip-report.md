**Total Soccer: Mundial — UI.SHARPNESS.1 + PLAYER.TOOLTIP.1, 4 жовтня 2026**

Виправлено спільний Team Selection grid для Quick Match і Penalty, уточнено scoreboard logos і збільшено player-name tooltip. Версія залишається 1.4.8, Android versionCode 8. Незакомічений пакет 1.4.8 збережено; staging, commit і push не виконувалися.

Причина розмиття mobile team-grid text: назва створювалася як Text 16 px із resolution 1, після чого дочірній visuals Container масштабував готову текстуру у 2 рази. Selected-team header створює назву безпосередньо у потрібному розмірі без такого масштабування. Тепер mobile label створюється одразу як 32 px, desktop — 16 px; Text і всі grid containers мають scaleX = scaleY = 1, resolution = 2. Font family Arial, weight 700, назви та кольори збережено. Origin змінився з (0, 0.5) на (0, 0), а вертикальне центрування використовує цілий локальний Y. Світові X/Y цілі, включно після wheel/drag: scroll offset округлюється до scene pixel.

Для grid logos виявлено дві структурні проблеми: desktop center X був дробовим через непарний розмір 27 px; drag/wheel могли залишити дробовий Y у спільному content container. Mobile logo вже мав ефективні 64×64 px: локальний image scale 0.5 компенсував parent scale 2. Тому саме parent scale не доводить окреме розмиття mobile logo у нерухомому grid. Він прибраний зі спільного UI; mobile logo тепер напряму відображається 64×64 при scale 1. Desktop logo став 28×28 із цілими центрами й краями. Джерела 64×64 WebP збережено.
