## Scoreboard та Event Log

Team code font: 32 → 35px. Square logos: 40 → 46px. Score font=64px, scoreboard height=78px, counter, score alignment та кнопки Pause/Rules збережені.

Лівий context block показує фактичний контекст матчу. Події SHOT / SAVE / POST тривають 3000ms; GOAL — 5000ms, із фактичними shirt number та player name. Наступна подія негайно замінює попередню. Вимірюється ширина рядка: короткий текст статичний, довгий прокручується зі швидкістю 45px/s, повтор із gap=36px. Дві копії тексту мають спільний geometry mask строго в межах context panel; розмір шрифту не зменшується. Таймер побудований на injected clock, тести без реальних очікувань.

GameEngine.appendLog спостерігає ті самі реальні GameEvent через окремий MatchEventLog. Знімки містять teams, ranks, names, shirt numbers, GK id за наявності, turn/move та рахунок. Записи й identity snapshots immutable; оригінальний GameState.log та його споживачі не змінені. UI тільки форматує журнал.

Типи: MATCH_START, BEAT, FAILED, TURN, SHOT, SAVE, POST, GOAL, MATCH_END. Приклад форматування реальних даних:

```text
#1 MATCH START
QUICK MATCH
UKR vs TUR

#2 BEAT
TUR Q #14 Erdoganli → UKR 4 #4 Melnyk

#3 FAILED
TUR 2 #2 Demirhan → UKR 10 #10 Romaniuk

#4 TURN TUR → UKR
```

Натискання центрального рахунку відкриває/закриває overlay без pause. Bounds: X=660, Y=140, width=280, height=520; текст 17px, mask, touch drag та wheel scroll. Межі не перекривають scoreboard, decks, GK, defense чи midfield cards. Панель живе поза gameplay layer, тому її scroll position переживає render карт. Нові записи автопрокручуються лише коли відстань до bottom ≤32px; читання історії не переривається. Повторне відкриття показує latest.

Пам'ять: повний журнал поточного match session, без persistence та без ліміту, який міг би приховати першу подію. Sequence починається з #1 у новому match, Restart, Play Again та наступному tournament match. Pause/Rules/resume зберігають той самий журнал. Unit test проходить увесь seeded match та порівнює GameState при читанні diagnostics і без читання.

Quick Match, Tournament group/playoff та Tutorial використовують цей GameEngine. PenaltyShootoutEngine має окрему модель подій; окремий penalty-only diagnostic model не додавали. Його header і далі показує PENALTIES через спільний ScoreView.
