Задача: доработать визуал футбольного поля на экране матча.

Контекст
Сейчас уже добавлены:
- внешний газон вокруг основного поля;
- ворота за линиями ворот;
- угловые дуги.

Но текущий результат нужно доработать визуально.

Что нужно изменить

1. Ворота
- Стойки ворот и перекладина должны быть визуально толще, чем линии сетки.
- Сейчас сетка и каркас выглядят почти одинаково по толщине — это нужно исправить.
- Каркас ворот должен читаться как основная конструкция.
- Сетка должна оставаться более тонкой и второстепенной.

2. Сетка ворот
- Сделать сетку более густой.
- Плетение сетки должно быть квадратным, а не прямоугольным.
- То есть шаг по горизонтали и вертикали должен быть одинаковым или максимально близким, чтобы ячейки выглядели квадратными.
- Сетка должна оставаться легкой и не слишком яркой, чтобы не перетягивать внимание с карт.

3. Внешний газон вокруг поля
- Газон за пределами основного поля должен быть полосатым, как и сам газон внутри поля.
- Важно: полосы внешнего газона должны визуально продолжать стиль основного поля.
- Не делать внешний газон однотонным.

4. Порядок слоев
- Внешний газон должен находиться под всеми UI-элементами.
- Сейчас он местами рисуется поверх табло, кнопок, колод и других элементов — это нужно исправить.
- Нужно, чтобы:
  - внешний газон был фоновым слоем;
  - поверх него были UI-панели, кнопки, табло, колоды, карточки статистики и прочие интерфейсные элементы.
- При этом сам основной матчевый field-area должен остаться визуально корректным.

5. Угловые дуги
- Уменьшить размер угловых дуг.
- Сейчас они слишком крупные.
- Сделать их аккуратнее и ближе к классической разметке футбольного поля.

Технические требования
- Менять только визуал поля.
- Не менять игровую логику.
- Не менять размеры и позиции карт, колод, табло, кнопок, интерактивных зон.
- Не ломать tutorial, AI, quick match, tournament.
- Сохранить текущую структуру FieldView, если это возможно, но при необходимости можно аккуратно реорганизовать код отрисовки слоев.

Что проверить после изменений
1. Quick Match:
- внешний газон полосатый;
- UI не перекрывается внешним газоном;
- ворота читаются лучше;
- сетка более густая и квадратная;
- угловые дуги меньше.

2. Tutorial Match:
- поле отображается корректно;
- overlay туториала, табло и кнопки не конфликтуют с новым фоном.

3. Визуальная иерархия:
- каркас ворот толще сетки;
- сетка не отвлекает от карт;
- внешний газон визуально поддерживает поле, но не мешает интерфейсу.

Тесты
- Обновить тесты, если они проверяют структуру/наличие элементов FieldView.
- Прогнать:
  - npm test
  - npm run build

- какие файлы изменены;
- как именно изменены ворота, сетка, внешний газон и угловые дуги;
- подтверждение, что логика игры не затронута;
- результаты npm test и npm run build.
