# Задание для Codex: создать инструкцию по смене цвета номеров на экипировках команд

## Контекст

Проект: `Total Soccer: Mundial`.

В игре номера игроков на футболках отображаются поверх изображений экипировок. Цвет номера и цвет обводки номера задаются не в самих WebP-изображениях, а в коде через registry экипировок.

Пользователю нужна простая инструкция, чтобы он сам мог менять цвета номеров для отдельных команд.

---

## Цель

Создать отдельный markdown-файл с понятной пошаговой инструкцией:

```text
как найти нужную команду
где менять цвет номера
где менять цвет обводки
как выбрать цвет
как проверить результат
```

Инструкция должна быть написана простым языком, без сложной технической терминологии.

---

## Где создать файл

Создать новый файл:

```text
docs/team-shirt-number-colors.md
```

Если папки `docs/` нет, создать ее.

---

## Что обязательно объяснить в инструкции

### 1. Где находятся настройки цветов номеров

Указать файл:

```text
src/data/teamKits.ts
```

Объяснить, что именно там задаются цвета номеров для команд.

---

### 2. Что не нужно менять

Обязательно написать:

* не нужно редактировать WebP-файл экипировки;
* не нужно добавлять номер прямо на картинку формы;
* не нужно менять файлы в `public/kits/images/`;
* не нужно менять `realSquads.ts`;
* не нужно менять номера игроков в составах.

---

### 3. Какие параметры отвечают за цвет

Объяснить параметры:

```ts
shirtNumberColor
shirtNumberStrokeColor
```

Где:

```text
shirtNumberColor — основной цвет номера
shirtNumberStrokeColor — цвет обводки номера
```

---

### 4. Пример изменения цвета номера

Добавить пример для Nigeria.

Пример:

```ts
{
  flagCode: 'nigeria',
  // другие параметры команды...
  shirtNumberColor: '#000000',
  shirtNumberStrokeColor: '#FFFFFF',
}
```

И объяснить:

```text
#000000 — черный номер
#FFFFFF — белая обводка
```

Важно: использовать фактический `flagCode`, который реально есть в проекте для Nigeria. Не выдумывать код. Нужно открыть `src/data/teamKits.ts` и взять реальную запись.

---

### 5. Примеры популярных цветов

Добавить короткую памятку:

```text
#000000 — черный
#FFFFFF — белый
#111111 — почти черный
#F5F5F5 — почти белый
#FFD700 — золотой
#FF0000 — красный
#0033A0 — синий
#00843D — зеленый
```

---

### 6. Как выбирать цвет

Объяснить простым языком:

* на светлой форме лучше черный номер;
* на темной форме лучше белый номер;
* если номер плохо читается, добавить контрастную обводку;
* для яркой формы лучше использовать номер с темной или светлой обводкой.

Примеры:

```ts
// светлая форма
shirtNumberColor: '#000000',
shirtNumberStrokeColor: '#FFFFFF',

// темная форма
shirtNumberColor: '#FFFFFF',
shirtNumberStrokeColor: '#111111',

// золотой номер на темной форме
shirtNumberColor: '#FFD700',
shirtNumberStrokeColor: '#111111',
```

---

### 7. Как проверить результат в игре

Описать простой способ:

1. сохранить файл `src/data/teamKits.ts`;
2. запустить проект:

```bash
npm run dev
```

3. открыть экран `Teams`;
4. выбрать нужную сборную;
5. посмотреть preview-карту справа;
6. затем запустить матч этой командой и проверить игровые карты.

---

### 8. Какие проверки выполнить перед коммитом

Добавить команды:

```bash
npm test
npm run build
```

Если были изменены только цвета номеров, `validate:kits` обычно не нужен, потому что WebP-ассеты не менялись.

---

### 9. Как закоммитить изменение

Добавить пример команд:

```bash
git status
git add src/data/teamKits.ts docs/team-shirt-number-colors.md
git commit -m "Document shirt number color settings"
git push
```

Добавить предупреждение:

```text
ToDo.md не добавлять в commit, если он изменен только как рабочий task-файл.
```

## Стиль инструкции

Инструкция должна быть:

* на русском языке;
* пошаговая;
* простая;
* понятная человеку без глубоких знаний TypeScript;
* с короткими примерами;
* без длинных архитектурных объяснений.

---

## Важные ограничения

Не менять игровую механику.

Не менять:

```text
GameEngine
GameEvent
GameScene
CardView
KitCardFaceView
realSquads.ts
public/kits/images/*.webp
```

Если Codex увидит, что фактические имена параметров отличаются от `shirtNumberColor` / `shirtNumberStrokeColor`, нужно использовать реальные имена из проекта и написать их в инструкции.
