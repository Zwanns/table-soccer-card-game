# Задание для Codex: убрать дублирующие названия команд из блока статистики ResultScene

## Контекст

Проект: `Total Soccer: Mundial`.

На послематчевом экране `ResultScene` вверху уже отображаются:

* флаг первой команды;
* код первой команды;
* итоговый счет;
* код второй команды;
* флаг второй команды.

Ниже расположен блок `MATCH STATISTICS`. Сейчас внутри этого блока над статистикой дополнительно отображаются коды команд слева и справа, например:

```text
BLR                         NGR
```

Эти строки дублируют верхнее табло и занимают место, которое лучше использовать для списка авторов голов.

---

## Цель

Убрать дублирующие коды команд из внутреннего блока статистики на послематчевом экране.

Нужно удалить/не рендерить строки с кодами команд внутри статистического блока:

```text
BLR
NGR
```

При этом верхнее табло с командами и счетом должно остаться без изменений.

---

## Где править

Основной файл:

```text
src/scenes/ResultScene.ts
```

Вероятные тесты:

```text
src/tests/resultScene.test.ts
```

---

## Что нужно изменить

### 1. Убрать внутренние team-code labels

В `ResultScene` найти место, где внутри блока статистики создаются текстовые объекты с кодами команд слева и справа.

Например, что-то похожее на:

```ts
this.add.text(leftColumnX, y, playerOneCode, ...)
this.add.text(rightColumnX, y, playerTwoCode, ...)
```

или helper, который создает team labels для статистического блока.

Эти labels нужно удалить или не создавать.

Важно: это касается только внутренних labels в блоке статистики.

Не трогать верхнее табло:

```text
flag + team code + score + team code + flag
```

---

### 2. Освободившееся место использовать для goalscorers

После удаления строки с кодами команд нужно поднять статистику или список авторов голов так, чтобы освободившееся место помогало при большом количестве голов.

Предпочтительный вариант:

* блок `GOALS / SHOTS / POSSESSION` оставить визуально примерно на текущем месте, если он выглядит хорошо;
* секцию `GOALSCORERS` и списки авторов голов поднять выше;
* увеличить высоту viewport/scroll area для списка авторов голов, если это возможно без нарушения layout.

Главная цель:

```text
больше места для списка goalscorers
```

---

### 3. Сохранить текущий layout и выравнивание

Не менять:

* верхнее табло результата;
* флаги;
* итоговый счет;
* фон;
* overlay;
* золотую рамку;
* названия статистических строк;
* формат авторов голов;
* левое выравнивание колонок goalscorers;
* scrolling goalscorers при переполнении.

---

## Ожидаемый результат

На послематчевом экране:

1. Вверху остаются команды и счет:

```text
BLR 4:3 NGR
```

2. Внутри блока `MATCH STATISTICS` больше нет дублирующих строк:

```text
BLR
NGR
```

3. Статистика остается:

```text
GOALS
SHOTS
POSSESSION
GOALSCORERS
```

4. Список авторов голов получает больше вертикального пространства.

---

## Тесты

Обновить `src/tests/resultScene.test.ts`.

Проверить:

1. верхние team-code labels по-прежнему создаются;
2. внутренние дублирующие team-code labels в статистическом блоке больше не создаются;
3. labels `GOALS`, `SHOTS`, `POSSESSION`, `GOALSCORERS` остаются;
4. goal scorers остаются left-aligned;
5. scroll/viewport для длинного списка авторов голов не сломан;
6. экран корректно работает при большом количестве голов.

Если в тестах есть snapshot/ожидания по количеству текстовых объектов, обновить их под новый layout.
