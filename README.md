# Total Soccer: Mundial

Версия: 1.4.0

Браузерная карточная футбольная игра для локальных матчей HUMAN vs HUMAN, HUMAN vs AI, AI vs HUMAN и AI vs AI. Проект совмещает футбольный матч, классические игральные карты, сборные, турнирные режимы, серии пенальти, статистику матча и просмотр составов с вымышленными фамилиями игроков.

## Возможности

- Матч на Phaser с футбольным полем, счетом, журналом событий, колодами, картами и индикатором преимущества.
- Локальная игра для людей и встроенного AI: красная и черная колоды, а также отдельные карты голкиперов.
- Tutorial Match v2: обучающий быстрый матч для новых игроков с подсказками, подсветкой карт и фиксированным сценарием Brazil vs Germany; учит базовому циклу, подключению полузащитников и открытым зонам. Тексты туториала доступны на EN / PL / UA и используют общий выбор языка с Rules.
- AI-режим для быстрого матча и визуальных матчей турнира без уровней сложности.
- Строгие правила подключенных полузащитников: равный rank не пробивается, специальные правила сохраняются.
- 66 национальных сборных с локальными флагами, цветами формы и обложками колод.
- Составы используют вымышленные фамилии игроков; реальные имена футболистов не используются.
- Экраны выбора команд, выбора составов и редактор составов.
- Турнирные режимы с групповой стадией, плей-офф, симуляцией матчей и сериями пенальти.
- Финальная статистика матча: авторы голов, владение, попадания в штангу, сейвы голкиперов и реализация моментов.
- Автоматические тесты для правил карт, игрового движка, составов, командных ассетов и турнирной логики.

## Быстрый старт

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Запустить тесты:

```bash
npm run test
```

Собрать production-версию:

```bash
npm run build
```

Готовая сборка создается в папке `dist/`.

## Команды

| Команда | Описание |
| --- | --- |
| `npm run dev` | Запуск Vite dev-сервера |
| `npm run test` | Однократный запуск тестов Vitest |
| `npm run test:watch` | Запуск Vitest в watch-режиме |
| `npm run build` | Type-check и production-сборка |
| `npm run sync:kits` | Обновить generated registry экипировок из `public/kits/images/*.webp` |
| `npm run validate:kits` | Синхронизировать registry и проверить WebP-экипировки |

## Экипировки

Чтобы добавить новую экипировку сборной:

1. Положить файл `public/kits/images/<flagCode>.webp`.
2. Проверить формат WebP и размер `702 x 900 px`.
3. Запустить `npm run validate:kits`.
4. Закоммитить новый `.webp` и generated registry.

Вручную добавлять `flagCode` в `AVAILABLE_MANUAL_KIT_FLAG_CODES` больше не нужно: registry генерируется из файлов в `public/kits/images/`. `npm run dev` и `npm run build` синхронизируют registry автоматически; запущенный dev-сервер также следит за добавлением, заменой и удалением `public/kits/images/*.webp` и перезагружает страницу. Reserved-файлы `none.webp`, `gk1.webp` и `gk2.webp` остаются fallback/goalkeeper assets и не входят в team registry.

## Примечания

- Игра рассчитана на запуск в браузере.
- Основные визуальные ассеты лежат локально, без зависимости от внешнего хостинга изображений.
- Игра не связана с FIFA, UEFA, национальными футбольными федерациями, клубами, лигами или игроками; флаги используются как идентификаторы стран, а формы, рубашки карт и визуальные элементы являются стилизованными.
- Пакет помечен как private и используется как приложение, а не как npm-библиотека.
